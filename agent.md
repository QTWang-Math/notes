# Agent Notes

## Folder Summary

This folder is a LaTeX-based mathematics notes repository.

Main components:
- `main.tex`: the root document, with preamble, theorem environments, macros, bibliography setup, and chapter inclusion.
- `TooYoung.sty`: a custom LaTeX style file for drawing Young diagrams/tableaux.
- `chapters/`: year-based note files, currently split into `2023.tex`, `2024.tex`, `2025.tex`, and `2026.tex`.
- `references.bib`: bibliography entries used by the notes.
- Image files such as `1.png`, `2.png`, `3.png`, `4.png`, and `Claude_Monet-NC.jpg`.
- `temp/`: LaTeX build artifacts such as `.aux`, `.log`, `.pdf`, `.xdv`, and related files.

## Topic Map

The notes are centered on geometric representation theory and related algebraic geometry topics:
- algebraic groups, tori, root data, and pinnings
- Harish-Chandra theory and Casselman-Wallach representations
- coherent continuation and regular characters
- nilpotent orbits, wavefront sets, and Whittaker models
- orbit method and geometric quantization
- flag varieties, conormal bundles, characteristic cycles, and perverse sheaves
- D-modules, local systems, and twisted differential operators
- symplectic singularities and quantization
