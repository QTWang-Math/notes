# Notes

Personal notes on representation theory, geometric representation theory, and related topics in algebraic geometry.

> The bad news is that we have still a long way to go.<br>
> The good news is that we have still a long way to go.
>
> - Alain Fournier, 1998

These notes are organized chronologically and continuously updated. They contain definitions, examples, calculations, references, and working observations rather than a finished exposition.

## Build

Compile the notes with XeLaTeX:

```bash
latexmk -xelatex -outdir=temp main.tex
```

The generated PDF is available at `temp/main.pdf`.
